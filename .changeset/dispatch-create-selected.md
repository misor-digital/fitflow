Create Speedy waybills for selected orders in the dispatch panel

The checkboxes in the dispatch table used to work only for cancelling waybills, and „Създай товарителници“ always created waybills for every pending order in the cycle. Orders without a waybill can now be selected too, and a new „Създай за избраните (N)“ button creates waybills only for the selected orders, each in its chosen Pick up / Drop off mode. This makes it possible to split a cycle into batches, for example to hand parcels over at two different Speedy offices by changing the drop-off office between batches. The select-all checkbox covers every selectable row, and „Анулирай избраните“ still applies only to selected waybills.
